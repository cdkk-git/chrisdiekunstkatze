ANDREW FONT AS SNES TILE DATA
Source: Andrew (embedded TrueType from the site), rasterised at 12 px, no anti-aliasing, 1 font pixel = 1 screen pixel.
Format reference: SnesLab Graphics Format (https://sneslab.net/wiki/Graphics_Format), CC BY 4.0.

FILES
  andrew.chr          SNES 2bpp tiles, 16 bytes per 8x8 tile, rows interleaved: [r0 bp0][r0 bp1][r1 bp0][r1 bp1]... bit 7 = leftmost pixel. 116 tiles, 1856 bytes.
  andrew_1bpp.chr     Same tiles at 1bpp (8 bytes per tile, 928 bytes). Not native to the SNES; expand to 2bpp by inserting a zero bitplane byte after each row.
  andrew.pal          4 colours, BGR555 little-endian (0bbbbbgggggrrrrr), 8 bytes. Index 0 = transparent, 1 = ink, 2 = green, 3 = red. The glyphs use index 1 only.
  andrew_spritesheet.png   Same tiles as an indexed PNG, 16 tiles per row, for viewing/editing.

LAYOUT
  Each character is an 8x16 cell = two stacked tiles (top rows 0-7, bottom rows 8-15). Baseline is at cell row 9 (9 rows above, 3 below).
  Identical tiles are stored once (tile 0 = blank). Characters are NOT in tile order: use the map below.
  advance = pixels to move the cursor after drawing (proportional font; ink is never wider than 8 px).
