CHRES' CASTLE - OPTIMIZATION LOG
Round 2: bigger cursor + 103 further optimizations
Applies to index.html, about.html, lionsgate.html, template.html (restrictions.html untouched on purpose).
Legacy note: new CSS sits in @media blocks and the script feature-detects, so IE4/IE8/PSP NetFront keep the original layout.

== BIGGER CURSOR (13) ==
  1. Main cursor enlarged 3x (16px -> 48px) on desktop/mouse devices.
  2. Link, menu and button cursor enlarged to match (the original two cursor images were identical, so one image is now shared).
  3. Enlarged with nearest-neighbour scaling so the pixel art stays crisp, not blurry.
  4. Hi-DPI screens get a 96px cursor via image-set() at 2x.
  5. Added -webkit-image-set() declaration for older WebKit/Blink browsers.
  6. Screens 1600px and wider get an even bigger cursor (64px, 128px at 2x).
  7. Custom cursor applies only to pointer:fine devices (mouse/trackpad); touch screens are untouched.
  8. Text fields keep the normal I-beam cursor so typing position stays clear.
  9. Cursor hotspot kept at 0 0 so the click point is still the arrow tip.
 10. Cursor images stored once in CSS custom properties instead of repeating the data in every rule.
 11. Cursor PNGs palette-quantised (~1 KB each).
 12. Fallback keywords (auto / pointer) kept after every cursor declaration.
 13. Cursor also applied to labels, buttons and submit inputs, not just links.
