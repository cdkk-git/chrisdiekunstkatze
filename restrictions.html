Table-Based Layout

This entire page is structured with an HTML table instead of CSS floats, flexbox, or grid, since PSP NetFront handles float-based layout unreliably and modern layout modules do not exist in either target browser.

Limitations Followed on This Page

Layout
  • Table-based layout only; no floats, flexbox, or grid
  • Fixed 460px width to fit the PSP's 480x272 screen
  • No CSS2/CSS3 selectors (:nth-child, :not, child/sibling combinators, attribute selectors)
  • Standards-mode doctype to avoid IE8 quirks-mode box model bugs
Visual styling
  • No border-radius, box-shadow, or gradients
  • No rgba()/hsla() colors; hex colors only
  • No CSS opacity or IE alpha filter (unsupported by NetFront and IE4)
  • No @font-face web fonts; system fonts only
  • No CSS transitions or animations
  • Font sizes in pt, not px/em, for IE4 reliability
Images
  • GIF/JPG only; no PNG alpha transparency
  • No SVG
JavaScript
  • Zero JavaScript used on this page
  • No AJAX/fetch; form uses a standard full-page GET submit
HTML
  • HTML 4.01 Transitional doctype
  • No HTML5 semantic tags (header, nav, section, etc.)
  • No <video>, <audio>, or <canvas>
